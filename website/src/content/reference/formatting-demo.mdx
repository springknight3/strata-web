## GFM Markdown Table

The table below verifies GitHub-Flavored Markdown table parsing and styling:

| Setting Key | Default Value | Description |
| :--- | :--- | :--- |
| `maxMemoryMb` | `4096` | Maximum heap allocation allocated to the JVM |
| `enableVsync` | `true` | Matches rendering refresh rate to primary monitor |
| `customJavaPath` | `null` | Optional override path to a custom Java installation |
| `reducedMotion` | `false` | Disables non-essential launcher interface animations |

All table borders, headers, and rows adapt seamlessly across light and dark themes.
