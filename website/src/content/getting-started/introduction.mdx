Welcome to StrataLauncher documentation! StrataLauncher is an open-source, high-performance launcher engineered for Minecraft: Java Edition.

## Overview

This documentation site provides setup guides, network troubleshooting steps, and technical references for developers and players alike.

<Note title="Hobby Project">
  StrataLauncher is a non-commercial community project and is not affiliated with Mojang Studios or Microsoft.
</Note>

## Key Features

- **Blazing Fast Startup**: Native desktop UI designed for smooth performance and responsive navigation.
- **Multiple Instance Management**: Easily manage isolated versions, mods, and mod loaders.
- **Modern Security**: Safe local credential storage and compliant authentication workflows.
